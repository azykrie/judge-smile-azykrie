Entry for the [Make the Judge Smile](https://make.fun/bounty/u-gentle-badger-68-make-the-judge-smile-9228676d) bounty on [make.fun](https://make.fun).

## The line

> The rain stopped the second I stepped out, and a scruffy orange cat I'd never seen fell into step beside me all the way to the warung, like it had been waiting for me.

(167 characters.)

## How it works

`main.py` is deterministic: it writes the same bytes to `/output/entry.txt` on every run, with no network access and no randomness.
